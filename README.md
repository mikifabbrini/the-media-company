# The Media Company — sito

Sito statico: un file HTML più la cartella delle foto.

- `index.html` — tutto il sito (testi, stili, script, loghi e mappa incorporati)
- `img/hero/` — le sei foto del carosello, in tre misure ciascuna
- `.nojekyll` — dice a GitHub Pages di servire i file così come sono

Il sorgente da cui si genera `index.html` sta in `redesign/site.src.html`
insieme allo script `build.py`.
